# interactive-quiz-system-python-tkinter
An interactive quiz application built using Python and Tkinter that allows users to log in, select subject and difficulty level, and attempt timed multiple-choice quizzes with real-time scoring and negative marking. It also provides instant result analysis with a leaderboard system using file handling to track and display top scores.
Features
🔐 User login and authentication system
📚 Subject selection (Python, DBMS, Computer Networks)
🎚️ Difficulty level selection (Easy / Medium / Hard)
⏱️ Timer-based quiz with automatic question switching
📊 Real-time scoring with negative marking
📈 Result summary with correct/wrong answers and percentage
🏆 Leaderboard system using file handling and Treeview

🛠️ Tech Stack
Python (Core Programming)
Tkinter (GUI Development)
File Handling
Data Structures (List, Dictionary)
Random Module
